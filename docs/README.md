# 小小偵探社｜GitHub Pages 靜態檔案

這個資料夾是由 Vite 建置產生的可部署靜態網站。

## GitHub Pages

1. 將本資料夾內的全部檔案上傳到 GitHub repository 的根目錄，或將本資料夾內容放入 `docs/`。
2. 到 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 選擇部署分支與 `/ (root)` 或 `docs` 資料夾。
4. 儲存後等待 GitHub Pages 發布。

網站使用相對路徑，支援 repository project site，例如 `https://帳號.github.io/repository/`。

## 本機預覽

可使用任意靜態伺服器預覽，例如：`python3 -m http.server 8080`。
